About this guide

A New England reference for harvesting forage for rabbits, poultry, goats, sheep, and other livestock. 78 of 78 plants cite at least one published source. Each plant page shows the passage behind each claim, and marks claims that still need a source. When sources disagree, the plant page says so.

This is a reference, not veterinary advice. When in doubt, leave it out and ask a vet.
