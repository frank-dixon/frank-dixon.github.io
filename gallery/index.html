01 / 07 Visualizer · Vite · PWA

Rabbit genetics

This is a coat and eye color calculator for meat-rabbit crosses. You pick two parents — breed presets or a custom genotype — and it lists the progeny phenotypes with percentages, genotype variants, and filters so you can hide the noise under five percent. I built it because I wanted it. Before Undercover Tourist I did genomics work at UMass Amherst, and I still raise rabbits; staring at a Punnett square on paper got old fast.

Under the hood it models the usual coat loci (A, B, C, D, E, plus En, V, Si) and rolls up outcomes so you see “Chestnut / agouti — 37.5%” instead of a wall of alleles. Each parent card has a Genetics & editing path when a preset is not enough. Saved crosses stick around for pairings you repeat. There is a How It Works / Learn Genetics / Citations strip if you want the biology instead of the clicky bit.

Use it by opening the live app, choosing an example cross or setting Dam and Sire, then reading the outcomes list. The hub ships a Vite production build under /rabbit/ with a service worker so the shell installs like a small PWA. Dark and light themes both work; I leave it dark most of the time.

02 / 07 Installable PWA · Open-Meteo

Weather PWA

A small installable weather app for me first, Springfield MA by default. It pulls Open-Meteo — no API key — and shows current conditions, feels-like, high/low, humidity, wind, the next hours, and a seven-day outlook. Temperatures stay in °F because that is how I actually read weather.

On a cold start it asks the browser for geolocation (“Near me”). If that is denied or times out it falls back to the last saved place, then Springfield. Favorites live in localStorage; star a city and the chips come back next visit. The interesting front-end bit is the offline path: the service worker caches the app shell, and the last forecast sticks around in Cache API plus local storage so a quiet moment on the phone still shows something useful.

Open the Pages URL, search a city or hit Near me, then use Install / Add to Home Screen when the browser offers it. On iOS Safari the in-app hint walks through Share → Add to Home Screen. After install it opens standalone. Plain HTML, CSS, and JS — no build step to fight.

03 / 07 Live cams · cream / teal

Hanalei Window

Kauai webcams on a quiet cream desk. Hanalei Bay up front, then Colony, Nourish, Lawai, Kalapaki. I built it for when I miss the north shore — favorite place besides home in Southwick, MA. It is not trying to be a travel product. It is a window I can leave open.

Technically it is intentionally boring in a good way: plain HTML/CSS/JS, no build, mobile-first. Feeds only embed when the resort or operator gives an embeddable page. Otherwise you get a full-bleed poster and an Open live cam link in a new tab, always credited. I do not scrape or rehost streams. When a feed is down, the offline poster stays honest instead of spinning forever.

Tap a chip to switch cams. If the embed is available it plays in place; if not, use the button and watch on the operator’s site. That constraint keeps the page light and keeps me out of ToS trouble.

04 / 07 Fungal genetics · canvas spaces

Hyphaneural

Hyphaneural is a fungal genetics demo dressed as four immersive spaces that share one pulsed purple–blue–green shell: Hex Reach, Strand Zoom, Fungal Atlas, and Void Breath. The pitch I care about is “see the strand, not the spreadsheet.” You land in baker’s yeast, follow a gene DNA → mRNA → protein, compare conserved families, and open a Genome panel for multi-organism tracks. No login on the Pages demo.

The interesting craft is the shell. Slow Ombre pulses underneath while you pan; HTML chrome is Tailwind utilities; the canvas stays vanilla JS. Seed data is static JSON, so the GitHub Pages build does not need Django even though the fuller local app can sit behind a thin JSON API. Start here opens Strand Zoom on SUC2 (invertase). Swipe sideways like a dial — or use the HEX / STRAND / ATLAS / VOID rail — to change spaces.

Open the live chamber, skip or walk the short intro, then zoom the rail from field to lattice to strand. Bands and Genome are there when you want comparison instead of atmosphere. It is a teaching toy with taste, not a lab LIMS.

05 / 07 Theme tokens · custom properties

CSS density demo

A static demo of CSS custom properties driving density and surface. Quiet vs Punchy changes spacing, type scale, radii, control heights, and shadow weight via data-density on <html>. Cream vs Alternate shifts the paper/ink grounds through data-surface while keeping the same turquoise accent. Same headline, cards, buttons, and form controls — they just breathe differently.

I built it to prove a point I keep making at work: theme kits should be tokens, not a second stylesheet you rewrite by hand. JavaScript only flips attributes and remembers the choice in localStorage. The Token peek panel shows live values like --space-md and --font-size-h1 so you can see the knobs move. Fraunces for display, Source Sans 3 for body — editorial on purpose.

Toggle Density and Surface at the top and watch the layout reflow without a route change. Read the essay and Browse notes are sample CTAs sitting on the same token stack. If you are auditing a design system, this is the smallest useful exhibit.

06 / 07 Design direction · one north star

Mood board

A mood board for a hub redesign I was arguing with myself about. One direction, not five options. Quiet editorial. Grown, not beige. Paper and ink, one turquoise accent, type doing the hierarchy work, whitespace instead of cards and chrome. Modern portfolio craft — not a late-2000s template and not techno-futurist glow.

The page itself is the artifact: references, type, color, sketches, rules. There is a Constraint → evolution callout that says keep cream / ink / turquoise, drop the dark cool-spectrum chrome when that direction wins, and ignore hero theater. The “What I pulled from” grid names sources and leaves a monospace Take under each so the notes stay concrete.

Read it top to bottom like a short brief. Jump the top nav to References, Type, Color, Sketches, or Rules. It lives on this hub under /mood-board/ because that is where the redesign conversation was happening. The live hub you are on now is still Cool Spectrum dark; this board is the alternate north star I wrote down so I would not forget it.

07 / 07 CSS craft · animation-timeline

Scroll progress

A quiet editorial demo where the top bar and chapter dots track how far you have read using animation-timeline: scroll() and named view timelines — not IntersectionObserver, not a scroll handler writing widths every frame. Most reading-progress widgets couple layout to JavaScript for something the browser can express declaratively now. I wanted a small FE taste piece that replaces that habit without punishing older browsers.

The bar uses animation-timeline: scroll(root) with a scaleX keyframe from 0 to 1. Chapter dots bind to named view-timelines on each section so as a chapter enters and settles, the matching dot lights. Everything sits behind @supports (animation-timeline: scroll()). Outside that fence the essay still reads fine; the scrubbing is progressive enhancement, not a dependency.

Open the page and scroll. Watch the bar and the Intent / Engine / Fallback / Taste dots. If your browser does not animate on scroll timelines yet, you will see a calm note and the same writing. That is the point.
